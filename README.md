# Family-Shop-Hub

Family Shop Hub: ứng dụng web cho hộ kinh doanh gia đình quản lý nhiều cửa hàng khác ngành (F&B, hàng có serial...) trong một tài khoản.

## Chạy thử

Cần Docker, Go 1.27 và Node 22.

```sh
make dev   # mở http://localhost:8080
```

`make help` liệt kê mọi lệnh. Tài liệu nghiệp vụ, kiến trúc và lộ trình nằm trong [`docs/`](docs/README.md); quy ước làm việc ở [`CLAUDE.md`](CLAUDE.md).
